# Hotel-Booking-EDA
Exploratory Data Analysis of Hotel Bookings using python
Hotel Booking EDA Project

Objective

To analyze hotel booking data and understand booking patterns and cancellations.

Tools Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

Analysis

- Data cleaning and preprocessing
- Univariate and bivariate analysis
- Multivariate analysis
- Numerical statistics and outlier analysis
- Logistic regression for cancellation prediction

Files

- "Inchara_HotelBookings_EDA_Project.ipynb"
- "hotel_bookings_cleaned.csv" (if included)

Conclusion

This project explores hotel booking trends and cancellation patterns using data analysis and visualization.
